
> A personal portfolio built somewhere between a developer workspace and a strange little digital world.


## ✦ About

Lost Apophis is my personal portfolio website.

I wanted to avoid the usual developer portfolio. Instead, the site is designed as a small visual world.

The background stays fixed while a large, translucent interface moves over it as the page is scrolled. The result is a simple **flat-stack** effect — there is no need for 3D elements or heavy visual effects to create depth.

The visual language takes inspiration from:

- Fantasy / RPG artwork
- Flat 2D game environments
- Editorial web design
- Dark interfaces
- Experimental typography
- Minimal but slightly chaotic compositions

The goal is to keep it artistic without making it feel like a game UI.

---

## ✦ The Idea

The website is built around one simple concept:

**a fixed world + a moving interface.**

The black, star-filled background acts as the environment.

The portfolio itself exists inside a large translucent interface window layered above it.

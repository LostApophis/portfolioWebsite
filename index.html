Character Bio.

I got into computers the way most people get into trouble: by taking something apart to see how it worked and not being sure I could put it back. Most of what I know about Linux and the shell comes from exactly that, from broken installs, bad configs and a stubborn refusal to just reinstall.

These days I write Python and Bash to automate the boring parts, Java and C++ when I want to see what the machine is really doing, and Angular when I want something I built to actually be looked at. I learn by building first and reading the docs when it breaks, which is slower but it sticks. Right now I'm digging into systems programming and trying to make my interfaces feel less like templates.
